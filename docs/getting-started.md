# Getting started

Use Node 24 LTS and npm. In a terminal:

```bash
npx degit kjarisk/vibeTemplate my-app
cd my-app
npm ci
npm run dev
```

Open the local URL printed by Vite, start Claude Code in the project, and run `/setup`. Describe the goal, users, scope, non-goals, data classification and hosting. Review the generated outline and plan before beginning. Skills and MCP servers are optional.

For the complete daily workflow, examples and agent guidance, see [Working with the template](working-with-ai.md). See [Quickstart](QUICKSTART.md) for scripts and commands and [Deployment](deploy.md) before publishing.
